# FondaControl---Sistema-POS-Control-Productivo-para-Fondas
FondaControl es un sistema POS + Control Productivo diseñado para fondas y cocinas económicas. Permite ventas rápidas, gestión de pedidos, control de inventario, margen de ganancia y dashboard analítico en tiempo real. Desarrollado con Python + Flask, MySQL, MongoDB y dashboard interactivo.
